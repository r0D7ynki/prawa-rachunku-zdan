## Goal
Powstaje strona `/kpn`: czym jest klauzula i koniunkcyjna postać normalna (KPN),
jak każdą formułę sprowadzić do KPN i jak w KPN łatwo sprawdzić tautologię.

## Context
Materiał z wykładu 1, slajdy „Przekształcanie formuł” (klauzule, KPN, test tautologiczności).
Strona rozszerza `base.html` i kończy się odnośnikami `/przeksztalcanie` (poprzednia)
i `/prawa` (następna).

Treść strony:

1. **Klauzula.** Alternatywa zmiennych zdaniowych lub ich negacji. Przykłady z wykładu:
   `(p ∨ q ∨ r)`, `(∼p ∨ q)`, `(p ∨ ∼q ∨ ∼r ∨ s)`.
   Napisz wprost: klauzula to „lista warunków połączonych słowem **lub**”.
2. **Koniunkcyjna postać normalna (KPN).** Formuła jest w KPN, jeżeli jest koniunkcją
   pewnej liczby klauzul. Przykłady z wykładu:
   `(p ∨ ∼q ∨ ∼r ∨ s) ∧ (∼p ∨ q) ∧ (r ∨ s ∨ ∼t)` oraz `p ∧ q ∧ (∼p ∨ ∼q)`.
3. **Każdą formułę można zapisać w równoważnej KPN.** Pokaż pełne wyprowadzenie z wykładu,
   krok po kroku, z nazwą prawa przy każdym kroku:

   ```
   (p → q) → ∼r          (prawo definiowania implikacji)
   (∼p ∨ q) → ∼r         (prawo definiowania implikacji)
   ∼(∼p ∨ q) ∨ ∼r        (I prawo de Morgana, podwójne przeczenie)
   (p ∧ ∼q) ∨ ∼r         (II prawo rozdzielności)
   (p ∨ ∼r) ∧ (∼q ∨ ∼r)
   ```

   Drugi przykład z wykładu (równoważność bez implikacji):

   ```
   p ≡ q                          (prawo zastępowania równ.)
   (p → q) ∧ (q → p)              (prawo definiowania implikacji)
   (∼p ∨ q) ∧ (∼q ∨ p)            (I prawo de Morgana)
   ∼(∼(∼p ∨ q) ∨ ∼(∼q ∨ p))
   ```

4. **Test tautologiczności w KPN.** Formuła w KPN jest tautologią wtedy i tylko wtedy,
   gdy w **każdej** klauzuli występuje pewna zmienna zdaniowa i jej negacja.
   Przykład tautologii z wykładu:
   `(p ∨ q ∨ ∼p) ∧ (∼p ∨ q ∨ r ∨ ∼q) ∧ (∼s ∨ s)`.
   Pokaż też kontrprzykład: `(p ∨ q) ∧ (∼p ∨ r)` **nie** jest tautologią, bo w drugiej klauzuli
   nie ma pary `x` i `∼x`.
5. **Dlaczego to jest przydatne.** Jedno zdanie: w KPN sprawdzenie tautologii to sprawdzenie
   każdej klauzuli osobno, bez wypisywania całej tablicy prawdy.
6. **Interakcja**: przycisk albo odnośnik do `/plac-zabaw?formula=<formula>` z celem `cnf`,
   żeby student sam sprowadził formułę do KPN. Jeżeli endpoint `/api/formula/simplify` działa,
   pokaż dla `(p → q) → ∼r` wynik `to_cnf` jako listę klauzul (każda klauzula jako osobny element listy).
