## Goal
Powstaje dokument `docs/URUCHOMIENIE-MACBOOK.md`. Osoba bez wiedzy technicznej uruchamia
stronę na MacBooku, wklejając komendy do Terminala.

## Context
Właściciel: „dopisz do dokumentacji jak to odpalić na MacBooku, zrób tak, żeby osoba totalnie
się nie znająca wklejając tylko do cmd była w stanie to uruchomić”.

Ustalenia techniczne:

1. Domyślny port 5000 na macOS obsługuje AirPlay Receiver. Instrukcja używa portu 5001.
2. Ścieżka bez `git` nie wymaga Xcode Command Line Tools: `curl` pobiera ZIP, `unzip` go
   rozpakowuje. Dzięki temu początkujący nie zobaczy okna instalacji narzędzi Apple.
3. `uv` sam pobiera Pythona. Użytkownik nie instaluje Pythona ani Flaska ręcznie.
4. Instalator `uv` zmienia profil powłoki. Bieżące okno potrzebuje `export PATH`.

Uwagi weryfikacyjne:
