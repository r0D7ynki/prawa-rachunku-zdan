## Goal
Partial `app/templates/partials/_truth_table.html` oraz skrypty
`app/static/js/truth-table.js` i `app/static/css/truth-table.css` pokazują interaktywną tablicę
prawdy. Kliknięcie wartości zmienia podświetlenie i pokazuje wynik dla wybranego ustawienia.

## Context
Kontrakt: `docs/ARCHITEKTURA.md`, sekcje „API” i „Frontend”. Partial dostaje zmienną `formula`
(tekst Unicode). Dane pobiera z `POST /api/formula/table` (PRZ-009), nigdy nie liczy logiki sam.

Zachowanie (bez odświeżania strony):
- nagłówek tabeli: kolumny zmiennych, potem kolumny podformuł z formułami w HTML `to_html`
  (notacja wykładowa: `∼`, `≡`),
- wiersze: wartości pokazuj jako `1`/`0` **oraz** słowa `PRAWDA`/`FAŁSZ` (`1` = PRAWDA),
  tak jak na wykładzie. Kolor nigdy nie jest jedynym nośnikiem informacji,
- dane biorą się z pola `znaki` odpowiedzi API (`1`/`0`) — nie przeliczaj wartości sam,
- kliknięcie komórki zmiennej przełącza jej wartość; tabela filtruje się do wierszy zgodnych
  z ustawieniem (aktywne filtry widać jako `aria-pressed="true"`),
- pod tabelą panel „Twoje ustawienie” pokazuje wartości zmiennych i wynik całej formuły słowami,
- podświetlenie wiersza po kliknięciu wiersza (klikalny wiersz, `tabindex="0"`, obsługa Enter i spacji),
- komunikat o błędzie po polsku, gdy API zwróci `ok: false` albo sieć zawiedzie,
- stan „wczytuję…” przed odpowiedzią,
- bez JavaScriptu widać komunikat, że tabela wymaga JavaScriptu, oraz wzór formuły.
