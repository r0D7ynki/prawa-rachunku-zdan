## Goal
Powstaje strona `/dowody`: dowód wprost, dowód nie wprost, wielokrotne założenia i czytanie
kontrprzykładu. Każdy dowód przechodzi się wiersz po wierszu, ze strzałkami od wierszy
użytych do nowego wiersza.

## Context
Treść: `docs/TRESC-WYKLAD2.md`, sekcje „3. Dowód założeniowy wprost”, „4. … nie wprost”,
„5. Niepoprawne rozumowania i kontrprzykład”. Dowody A–F są tam wypisane wiersz po wierszu.

`app/logic/proofs.py` (dane, nowy plik):

```python
@dataclass(frozen=True)
class ProofLine:
    nr: str            # "1", "4.1"
    formula: str       # "(p ∨ q) → (r ∨ s)"
    uzasadnienie: str  # "RO 2, 3" albo "Założenie" albo "Sprzeczność 5, 7"
    z: list[str]       # numery wierszy, z których korzysta: ["2", "3"]

@dataclass(frozen=True)
class Proof:
    id: str            # "A", "B", "C", "D", "E", "F"
    tytul: str
    rodzaj: str        # "wprost" | "nie-wprost" | "wielokrotne"
    teza: str          # formuła tezy do pokazania
    wiersze: list[ProofLine]
    opis: str

def proofs() -> list[Proof]
def get(proof_id: str) -> Proof | None
```

Strona `/dowody`:
- wstęp: na czym polega dowód założeniowy (2–3 zdania na każdy rodzaj),
- zakładki (albo sekcje) dla dowodów A–F,
- pod tabelą wierszy pasek kroków (komponent PRZ-072): każdy krok odkrywa jeden wiersz dowodu,
- przy odkrywanym wierszu rysowane są **strzałki** od wierszy z listy `z` do nowego wiersza,
  z opisem reguły („RO”), a wiersz „Sprzeczność 5, 7” podświetla oba sprzeczne wiersze na
  czerwono i kończy dowód,
- wiersze 4.1–5.4 (dowód F) pokazują wcięcie i podpis „Dodatkowe założenie”,
- sekcja „Skąd kontrprzykład”: tabela z `docs/TRESC-WYKLAD2.md`, sekcja 5, z dwoma przykładami
  i wypisanym kontrprzykładem,
- bez JavaScriptu: wszystkie wiersze dowodu widoczne jako tabela (jak w wykładzie).
