## Goal
Diagramy bramek i zbiorów rysuje **Python**, nie przeglądarka. Dzięki temu działają zawsze
i sprawdza je test. Każda strona prawa pokazuje oba rysunki.

## Context
Uwagi właściciela: „wykresy jak w prawie de Morgana dodaj wszędzie, tylko nie działają” oraz
„zrób, by działało faktycznie”.

**Przyczyna:** dziś rysunki powstają w przeglądarce (`sets.js`, `gates.js` pobierają dane
z `/api/formula/parse` i wstawiają SVG przez `createElementNS`). Serwer i API działają —
przeglądarka wysyła żądania — ale rysunek nie powstaje. Tego nie da się sprawdzić testem
w Pythonie. Dlatego rysunek przenosimy na serwer.

Nowy moduł `app/logic/diagrams.py`:

```python
def gates_svg(node: Node, wartosci: dict[str, bool], krok: int | None = None) -> str
def sets_svg(node: Node, krok: int | None = None) -> str
def kroki_gates(node: Node) -> list[dict]   # [{"opis": "…", "bramka": 3}, …]
def kroki_sets(node: Node) -> list[dict]    # [{"opis": "…", "operacja": "suma"}, …]
```

Zasady rysowania:
- **Zbiory**: prostokąt to cała przestrzeń, koła to zbiory zmiennych (najwyżej 3).
  Obszar licz na siatce **44 × 36** próbek; przebiegi prawdziwych próbek w wierszu sklej
  w jeden `<rect>` (albo `<path>`). Wynik wstawiaj przez `markupsafe.Markup` — to nasz HTML,
  nie dane użytkownika. Każdy obszar ma `fill` z klasy (`obszar-1`, `obszar-2`) i `<title>`
  z opisem po polsku.
- **Bramki**: układ licz w Pythonie (kolumna = głębokość w drzewie, wiersz = kolejność liści).
  Każda bramka to prostokąt z symbolem (`∼`, `∧`, `∨`, `→`, `≡`), każdy przewód to `<path>`
  ze `stroke-marker` (strzałka) i `<title>` z wartością. Wartości liczy `truth.evaluate`
  dla podformuł — nie ma tu żadnego API.
- **Kroki**: `kroki_*` zwracają listę kroków z opisem po polsku. Krok `i` rysuje stan po
  `i`-tej operacji. Diagram pokazuje krok `krok` z parametru.

Zmiany w widoku i partiale:
- Karta PRZ-010 zmienia `app/blueprints/laws.py` tak, żeby do szablonu trafiały **oba**
  diagramy (`gates_svg`, `sets_svg`) plus listy kroków — niezależnie od pola `wizualizacja`.
- `app/templates/partials/_gates.html` i `_sets.html` wstawiają gotowy SVG z serwera.
  Zostaje tylko skrypt `wizualizacje.js` (nowy, ~40 linii) obsługujący dwie strzałki
  „‹ poprzedni” / „następny ›”, które podmieniają `src`/zawartość z **prefetched** kroków
  zapisanych w `<template>`; bez JavaScriptu widoczny jest pierwszy krok i lista opisów.
- **Bez numerków kroków**: żadnego „krok 3 z 7”, żadnych kropek, żadnego „Odtwórz”.
  Tylko dwie strzałki. Opis kroku jest tekstem pod rysunkiem.
