## Goal
Powstaje `app/logic/rules.py` z rejestrem reguł wnioskowania i strona `/reguly` z kartami reguł.

## Context
Treść, kody i przykłady: `docs/TRESC-WYKLAD2.md`, sekcja „2. Reguły wnioskowania”. Nic nie
wymyślaj — wszystkie dane są w tym pliku.

`app/logic/rules.py`:

```python
@dataclass(frozen=True)
class Rule:
    kod: str            # "RO", "OK", "DK", "OA", "DA", "DR", "OR", "DM1", "DM2", "KP"
    nazwa: str          # "Reguła odrywania"
    pelna_nazwa: str    # "Modus Ponens" albo ""
    typ: str            # "pierwotna" | "dodatkowa"
    przeslanki: list[str]   # ["Φ → Ψ", "Φ"]
    wniosek: str            # "Ψ"
    tautologia: str         # "((p → q) ∧ p) → q"
    przyklad: str
    opis: str               # 1-2 zdania prostym językiem

def rules() -> list[Rule]     # pierwotne wg tabeli, potem dodatkowe
def get(kod: str) -> Rule | None
```

Strona `/reguly` (moduł `app/blueprints/reguly.py`, szablon `reguly.html`, styl `reguly.css`):
- sekcje „Reguły pierwotne” i „Reguły dodatkowe”,
- karta reguły: kod i nazwa, przesłanki nad kreską, wniosek pod kreską (kreska to element
  HTML/CSS, nie znak `—`), tautologia przez `formula.to_html`, przykład z życia, opis,
- odnośnik „Sprawdź w placu zabaw” z tautologią reguły,
- na górze krótkie wyjaśnienie, czym jest reguła wnioskowania,
- strona działa bez JavaScriptu.

W tym samym commicie dopisz sekcję o `app/logic/rules.py` do `docs/ARCHITEKTURA.md`.
