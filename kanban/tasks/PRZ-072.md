## Goal
Powstaje jeden komponent do prowadzenia użytkownika krok po kroku: `stepper.js`, partial
`_stepper.html` i `stepper.css`. Korzystają z niego tablica prawdy, bramki, diagramy zbiorów
i dowód tautologii.

## Context
Uwaga właściciela: „jak masz wykresy, to zrób je interaktywne, jak po kolei to idzie, bo wynik
końcowy niewiele daje”. Jeden komponent zamiast czterech osobnych to mniej kodu i spójne
zachowanie.

Kontrakt (udokumentuj go w `docs/ARCHITEKTURA.md` w tym samym commicie):

```js
import { createStepper } from "/static/js/stepper.js";

const stepper = createStepper({
  mount: document.querySelector("#kroki"),   // element, w którym powstaje pasek
  steps: [{ tytul: "...", opis: "..." }],    // co najmniej 1 krok
  onStep: (index, step) => { ... },          // co pokazać po wejściu w krok
  autoMs: 1500,                              // tempo odtwarzania
  labels: { prev: "Wstecz", next: "Dalej", play: "Odtwórz", pause: "Pauza", reset: "Od nowa" }
});
// sterowanie: stepper.go(3), stepper.next(), stepper.prev(), stepper.play(), stepper.pause(),
// stepper.reset(), stepper.index
```

Wymagania:
- pasek ma przyciski: „Wstecz”, „Dalej”, „Odtwórz/Pauza”, „Od nowa” oraz wskaźnik „krok 3 z 7”,
- kropki kroków są klikalne (`<button>`), bieżąca ma `aria-current="step"`,
- cały pasek działa z klawiatury: strzałki w lewo/prawo, `Home`, `End`, spacja zatrzymuje
  i wznawia odtwarzanie,
- `onStep` dostaje `(index, step)`, a komponent nigdy nie pisze do DOM poza paskiem i poza
  elementem `opis` — resztę rysuje karta, która go używa,
- treść kroku jest ogłaszana przez `aria-live="polite"`,
- brak JavaScriptu: partial pokazuje listę wszystkich kroków jako listę `<ol>` (statyczny opis),
- `Mount` bez `steps` nie rzuca błędu, tylko pokazuje komunikat po polsku.

### Decyzje wykonawcy (dopisane do `docs/ARCHITEKTURA.md`)

- **Indeks kroku liczony od zera** (`go(2)` to trzeci krok), wskaźnik pokazuje numer od jednego.
  Tak zakłada karta PRZ-075 („Krok 0 pokazuje obszar lewej strony”).
- **`onStep` wołane też przy tworzeniu** paska (pierwszy krok) i przy każdej zmianie kroku;
  samo odświeżenie paska (np. pauza) go nie powtarza.
- **`destroy()`** — funkcja spoza kontraktu z karty: bez niej `play()` zostawiałby działający
  `setInterval` po usunięciu paska. Opisana w `docs/ARCHITEKTURA.md`.
