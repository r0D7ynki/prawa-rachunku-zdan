## Goal
Powstaje moduł `app/lessons.py`: rejestr wykładów i lekcji. Z niego korzysta menu, spis treści,
okruszki, „poprzednia/następna lekcja” i strona `/spis-tresci`.

## Context
Dziś kolejność stron jest rozrzucona po szablonach. Dodanie wykładu 2 oznaczałoby edycję wielu
plików. Rejestr rozwiązuje problem: nowy wykład to jedna lista w jednym pliku.

Struktura (dokładnie te nazwy pól):

```python
@dataclass(frozen=True)
class Lesson:
    slug: str          # "formuly"
    sciezka: str       # "/formuly"
    tytul: str         # "Formuły i wartościowanie"
    opis: str          # jedno zdanie, do 20 słów
    wyklad: int        # numer wykładu
    ikona: str         # krótki znak, np. "≡"

@dataclass(frozen=True)
class Lecture:
    numer: int
    tytul: str         # "Klasyczny rachunek zdań"
    opis: str
    lekcje: tuple[Lesson, ...]
    gotowy: bool       # False = „wkrótce”
```

Funkcje:
- `lectures() -> list[Lecture]` — w kolejności numerów,
- `lessons() -> list[Lesson]` — wszystkie lekcje po kolei (płaska lista),
- `lesson(sciezka: str) -> Lesson | None` — lekcja po ścieżce,
- `lecture(numer: int) -> Lecture | None`,
- `previous(sciezka)` i `next(sciezka)` — sąsiedzi w płaskiej liście (albo `None`),
- `tool_links() -> list[dict]` — pozycje narzędziowe: Prawa `/prawa`, Plac zabaw
  `/plac-zabaw`, Quiz `/quiz`, Słowniczek `/slowniczek`, Jak czytać `/jak-czytac`.

Treść rejestru — wykład 1 (gotowy), lekcje w tej kolejności:
`/wstep`, `/formuly`, `/tautologie`, `/przeksztalcanie`, `/kpn`, `/prawa`, `/plac-zabaw`, `/quiz`.
Wykład 2 „Rachunek predykatów” i wykład 3 „Elementy teorii zbiorów i relacji” wpisz jako
`gotowy=False` z pustą listą lekcji — to zapowiedź na przyszłość.

Kontekst szablonów: w `create_app` dodaj `app.context_processor`, który wstrzykuje do każdego
szablonu `NAV = {"lectures": ..., "lesson": lesson(request.path), "previous": ..., "next": ...,
"tools": ...}`. Dzięki temu szablony nie wołają funkcji Pythona.

W tym samym commicie dopisz sekcję o rejestrze do `docs/ARCHITEKTURA.md` (zasada 2 w `AGENTS.md`).
